# Dr. José Artur | Landing Page Institucional

Landing page desenvolvida para um cirurgião-dentista com foco em conversão, autoridade profissional e agendamento direto por WhatsApp.

## Sobre o projeto

Este projeto foi criado para apresentar o perfil de um profissional da odontologia de forma moderna, clara e persuasiva. A interface combina estética premium, comunicação objetiva e estrutura otimizada para transformar visitantes em pacientes.

A página destaca formação, áreas de atuação, diferenciais, conquistas e depoimentos, reforçando a confiança do público e facilitando o contato inicial com o consultório.

## Destaques

- Interface responsiva e moderna
- Foco em conversão para WhatsApp
- Destaque para especialidades e diferenciais
- Seções de formação, conquistas e depoimentos
- Visual otimizado para mobile e desktop
- Estrutura organizada para manutenção e evolução

Desenvolver uma landing page institucional com alto impacto visual e experiência focada em conversão, reforçando a presença digital do profissional e agilizando o processo de agendamento.

## Publicação no GitHub Pages

O workflow em `.github/workflows/deploy-pages.yml` compila e publica automaticamente o conteúdo de `dist` ao enviar alterações para `main` ou `master`.

No GitHub, abra **Settings > Pages** e selecione **GitHub Actions** como fonte de publicação. O caminho base do Vite está configurado para o repositório `-website-cirurgiao-dentista`; se o nome do repositório mudar, atualize `base` em `vite.config.ts`.
